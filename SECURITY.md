# Security policy

Do not report credentials, private prompts, personal data or customer information in a public
issue. Contact the HubTech maintainers through an established private channel and include only the
minimum information needed to reproduce the problem.

The catalog must never contain secrets. If a secret is discovered, treat it as compromised,
revoke it at its authority and notify the maintainers privately; deleting Git history is not a
substitute for revocation.
