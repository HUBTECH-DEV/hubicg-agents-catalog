# Contributing

Open an issue before preparing a new public definition. Never submit private prompts, chat
history, credentials, personal data, customer material, employer-owned material without written
authority, internal endpoints, tenant configuration or proprietary customer implementation.

A pull request must:

1. change only catalog, schema, documentation or catalog-validation paths;
2. classify every new definition as `community` in `catalog/manifest.json`;
3. record its origin, immutable source revision, content SHA-256 and applicable license;
4. include evidence that the contributor is entitled to submit it;
5. pass the catalog boundary validator; and
6. receive approval from a HubTech code owner who is not the change author.

External contributions remain blocked until the applicable Individual CLA or Corporate CLA has
been legally reviewed, accepted and recorded. An email domain or GitHub organization membership
does not prove copyright ownership.
